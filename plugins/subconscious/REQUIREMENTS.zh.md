# 潜意识需求

潜意识是心跳。它不代替主意识说话。第一版只做三件事：读自己的前缀，按间隔醒来，看见这段时间里收集到的事件。

它有自己的一条长期 session。主意识的 session 不并进这条日志里。每次醒来，把主意识各条 session 自上次心跳以来的新事件拼进这一轮的上下文。这样它看得到自己以前想过的话，也看得到外界和其他意识刚刚发生的事。

会话日志、压缩、提示词组装和工具循环用 Harness 现有的。

## 前缀

固定提示词和主意识放在同一个目录。不扫描目录，只按本插件自己的文件名列表读取、拼成一段。名单可以和主意识不同，缺的文件按主意识同一条规则处理：`SOUL.md` 若在名单里且为空，这一轮不醒；其余缺失或为空就跳过。

加载方式和主意识相同：`complete: true`、`interpolate: false`，每次醒来重新读盘。

## 定时唤醒

间隔是配置，单位秒。到点醒一次。

上一次还没结束时，不另开一轮。这期间新到的事件继续积着，等这一轮结束、下一次到点再看。没有新事件也可以醒。醒了没有要做的事，就在自己的 session 里留下一句安静结束，不对外发送。

## 这一轮能看见什么

事件从两条线来。

自己的 session 里，是以往心跳写下的内心活动。它本来就在这条上下文中，不需要再复制一份。

主意识的每一条 session 里，只取上次心跳之后新发生的部分，按时间拼在这一轮前面。现在主意识是一条 session。以后若有多条，全部纳入，不挑一条最近的聊天来代替。

第一版至少包括这些事件：

- 外界进来的文字：渠道、会话、谁说的、正文
- 主意识的 `send_text`：对谁说了什么，以及发出去没有
- 主意识的 `pass`：这轮选择不说
- 主意识这轮写下的 `thought`、`mood`、`decision`、`expected_response`

图片、文件、语音在主意识第二阶段进入之后，以同样的方式出现在心跳里。第一版还没有这些事件时，不要编造看见了。

## 这一版不做

不对外发送。没有 `send_text`。不主动给谁开口，不写回记忆文件，不搜记忆，不管理技能，也不设休息锁。那些是心跳以后的能力，不挡这一版。
