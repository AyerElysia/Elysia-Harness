# Proactive system

爱莉主动系统的独立插件边界，目标是以**异步机会**连接主潜意识同步、好奇线索、注意力线索、计划与未完话头。

当前仅为占位：`apply()` 不注册任何运行时行为。没有定时器、后台任务、session、模型调用、存储、渠道发送或模型工具，也没有加入当前 Web profile。

完整目标、认知与工程边界、内部记录草案及未来验收条件见 [REQUIREMENTS.zh.md](REQUIREMENTS.zh.md)。

核心方向不是定时替她说一句话，而是：后台准备机会，在主意识空闲时明确呈现，由她亲自决定行动、搁置、拒绝或 `pass`，并保留真实因果记录。

从 `dsh` 工作区运行占位生命周期测试：

```sh
pnpm --filter @elysia/proactive-system test
```

该测试只验证无行为插件可以挂载和卸载，不验证任何尚未实施的主动能力。
