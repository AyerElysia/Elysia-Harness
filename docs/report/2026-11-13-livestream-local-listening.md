# DSH 直播彩排本机试听验收

2026-11-13，北京时间。

原直播会话能够接收弹幕、生成回复并合成语音。浏览器声音页多次报告播放超时。原 DSH 内嵌舞台是静音预览，用户当前需要直接在 DSH 页面试听。

本机试听在无平台房间且发布空闲时显示。用户在试听页主动启用，浏览器以短静音 PCM 预热页面内的同一播放器，随后才注册试听连接。宿主每句只分配一个播放器，彩排优先交给已启用的试听页。停止试听或失去彩排条件会清理连接和播放。直播姬独立声音与字幕源继续使用原有协议。语音回执区分加载、起播和播放阶段，成功只接受真实播放完成。

TypeScript 与 328 项自动测试通过，6 项按既有条件跳过。Spark Firefox 的跨端口 iframe 实测中，启用前试听连接数为零。点击启用后，1.520 秒 Breeze WAV 仅交给试听页，真实起播并结束，普通声音源和字幕源均未收到该句。停止试听后，下一句由普通声音源真实播完，字幕出现后清空。

正式 DSH 已切换。Windows 本机 3300 的试听、声音和字幕地址均返回 200，旧会话正常加载。发布仍空闲。实际 Windows 听感需要从用户打开的 DSH 页面确认。
