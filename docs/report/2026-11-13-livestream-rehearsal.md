# 直播控制台断线与本地彩排恢复

2026-11-13，北京时间。B 站房间已下播，本地彩排未接入直播间。

截图的 `Failed to fetch` 是控制台未取到宿主状态。Windows 3299 转发当时缺失，3300 的浏览器源入口和 Spark 后台可用。重新建立本机 3299 转发后，增加状态读取的退避重试和明确的加载、断线提示。操作 POST 仍由用户触发一次。

正式服务的固定直播会话启动一度返回 400。现有会话在持久化中，回退创建被原生存储拒绝。隔离复现确认，复制安装的插件和原生 DSH 同时加载了不同实例的作用域及会话模块。前者导致插件读不到 Agent 作用域，后者导致记录写入的私有类校验失败。注册工具时使用原生提供的固定 Agent 和同一上下文；将 Web profile 的直播插件切换到本地源码链接，使插件和原生解析到同一模块。原会话与其历史保留。

- TypeScript 检查、54 项直播相关定向测试通过，另用生产安装图和合成会话分别复现及核验。
- 模拟观众测试标记「银杏灯」进入固定直播会话 seq 1168，关联投影 1184，爱莉的回复为 1190，轮次正常结束。语音合成后声音页回报播放超时，回执为 1193。确认了弹幕接收和文字回应，声音未取得播放完成回执。
